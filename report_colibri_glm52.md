# Colibri — Запуск GLM-5.2 (744B параметров) на домашнем ПК

**Дата исследования:** 15 июля 2026
**Источник:** https://github.com/JustVugg/colibri

---

## Что это?

Colibri — легковесный движок для запуска гигантской модели **GLM-5.2 (744 миллиарда параметров, MoE — Mixture of Experts)** на обычном домашнем компьютере с ~25 ГБ оперативной памяти. Без видеокарты. На чистом C.

## Ключевая идея

Модель MoE активирует лишь ~40 млрд параметров на каждый токен. Из них только ~11 млрд меняются от токена к токену (routed experts). Colibri использует это:

- **Плотная часть** (attention, shared experts, embeddings — ~17B параметров) — живёт в RAM в int4 (~9.9 ГБ)
- **21 504 эксперта** (75 MoE слоёв × 256 экспертов + MTP head, ~19 MB каждый в int4) — хранятся **на диске** (~370 ГБ) и подгружаются по требованию

## Технические детали

| Характеристика | Значение |
|---|---|
| Модель на диске (int4) | ~370 ГБ |
| RAM (плотная часть) | 9.9 ГБ |
| Пиковый RSS | ~20 ГБ (авто-ограничение) |
| Время загрузки | ~30 секунд |
| Движок | Один C-файл (~2400 строк) |
| Зависимости | Нет Python, нет библиотек, не нужен GPU |
| Скорость (среднее железо) | 0.05–0.1 токен/с (cold cache) |
| С MTP спекуляцией | 2.2–2.8 токен/форвард |

### Как читает с диска

Один токен в холодном кэше требует чтения ~11 ГБ с диска. На NVMe (~1 ГБ/с) это даёт ~0.05–0.1 ток/с. Горячий кэш + pinned эксперты + MTP спекуляция значительно ускоряют.

### Ключевые оптимизации

1. **MLA attention** — сжатый KV-cache: 576 floats/токен вместо 32 768 (в 57× меньше!)
2. **MTP спекулятивное декодирование** — встроенный multi-token-prediction head предсказывает следующие токены, основной модель проверяет их пачкой (acceptance rate 39–59%)
3. **Grammar-forced drafts** — когда контекст допускает лишь один легальный байт (JSON, enum), грамматика форсирует предсказание
4. **Async expert readahead** — пока блок экспертов умножается, ядро уже читает следующий
5. **Router-lookahead prefetch** — предсказание, какие эксперты понадобятся на следующем слое (71.6% точность)
6. **Batch-union MoE** — в prefill каждый эксперт читается один раз и применяется ко всем позициям

### Результаты на 6× RTX 5090

С полным размещением экспертов в VRAM+RAM: **6.84 ток/с** (single-request decode).

## Ограничения

- На среднем SSD скорость ~0.1 ток/с (cold) — медленно, но работает
- MTP с int4 head даёт 0% acceptance — нужно int8 (штатно конвертер так и делает)
- Не байт-идентичен с не-спекулятивным режимом из-за rounding в int4
- Активное охлаждение SSD желательно при длительной работе

## Вывод

**Colibri делает невозможное возможным:** запускает модель на 744 млрд параметров на компьютере, который стоит меньше чем один вентилятор от H100. Да, медленно — но модель отвечает правильно. Это proof of concept, который переопределяет понятие "минимальные требования".
